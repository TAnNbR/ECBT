# AssetToken withdrawDividend 函数测试用例详解

## 测试概述

本文档详细说明 `AssetToken` 合约中 `withdrawDividend` 函数的所有测试用例。该函数是分红和清算金提取的核心函数，集成了 `_calculateDividendAmount` 和 `findLiquidationTimeRange` 两个关键功能。

## 测试环境

### 测试参数
- **资产名称**: Test Real Estate Token
- **资产符号**: TRE
- **资产总价值**: 1,000,000 USDT
- **募集金额**: 500,000 USDT
- **代币总供应量**: 1,000,000 代币
- **季度预期分红**: 10,000 USDT
- **季度周期**: 7 天（便于测试）
- **清算比例**: 20%

### 辅助合约
- **MockERC20 (paymentToken)**: 模拟 USDT (6位小数)
- **CollateralVault**: 真实的抵押金库合约
- **RevenueManager**: 真实的收益管理合约（时间单位：DAY）
- **LiquidateManager**: 真实的清算管理合约
- **AssetToken**: 资产代币主合约

### 核心功能集成

`withdrawDividend` 函数集成了两个关键计算：
1. **分红计算**: 通过 `_calculateDividendAmount` 计算持有期间的分红
2. **清算次数查找**: 通过 `findLiquidationTimeRange` 计算清算次数

### 一、基本分红提取（无清算）(9个)

#### 1. 单笔收益提取

**测试目的**: 验证基本的单笔分红提取流程

**前置条件**:
- buyer1 购买全部 1,000,000 代币（100% 持有）
- 等待售罄后（`soldOutTimestamp + 1 day + 1 second`）

**测试步骤**:
1. 等待 1 天
2. provider 存入 5,000 USDT 到 CollateralVault
3. RevenueManager 记录该笔收益
4. 等待 2 天
5. buyer1 提取分红

**预期结果**:
```
分红 = 5,000 USDT × 100% = 5,000 USDT
```

**验证点**:
- 分红金额精确匹配
- 资金正确转移

**业务意义**: 验证单笔分红的基本提取流程

## 关键技术点

### 1. withdrawDividend 核心逻辑

```solidity
function withdrawDividend(address recipient, address holder) 
    public onlySoldOut() returns (uint256)
{
    // 1. 遍历所有 HolderInfo，分别计算分红和清算
    for (uint256 i = 0; i < holderInfo[holder].length; i++) {
        // 计算分红（调用 _calculateDividendAmount）
        dividendAmount += _calculateDividendAmount(
            lastDividendTime, 
            withdrawTime, 
            info.shares
        );
        
        // 计算清算次数（调用 findLiquidationTimeRange）
        liquidationCount += findLiquidationTimeRange(lastClaimTime);
    }
    
    // 2. 转移分红和清算金
    transferRevenue(recipient, dividendAmount);
    transferLiquidatableCollateral(recipient, totalShares, totalSupply, liquidationCount);
    
    // 3. 合并所有份额，更新时间戳
    delete holderInfo[holder];
    holderInfo[holder].push(合并后的份额);
}
```

### 2. 分红计算公式

```
分红 = Σ(每个份额的分红)
每个份额的分红 = (份额 / 总供应量) × 期间总收益
```

### 3. 清算金计算公式

```
清算金 = (总份额 / 总供应量) × 单次清算金额 × 清算次数
单次清算金额 = 总抵押金 × 20%
清算次数 = findLiquidationTimeRange(holdingStartTime)
```

### 4. 时间戳更新机制

```
提取后：
- lastDividendTime = withdrawTime
- lastLiquidationClaimTime = withdrawTime
- holdingStartTime = INVALID_TIMESTAMP（合并后不再需要）
```

### 5. 售罄时间机制

```solidity
// 设置（purchase时）
soldOutTimestamp = block.timestamp + 1 days;

// 检查（withdrawDividend时）
require(
    soldOutTimestamp != 0 && 
    block.timestamp > (soldOutTimestamp + 1 days),
    "Token not sold out yet"
);
```

## 关键验证点

### 1. 函数集成正确性
- `_calculateDividendAmount` 正确计算分红
- `findLiquidationTimeRange` 正确统计清算
- 两者结果正确累加

### 2. 时间管理与增量计算
- `lastDividendTime` 和 `lastLiquidationClaimTime` 独立追踪
- 两个时间戳同时更新到 `withdrawTime`
- **增量计算机制**: 只计算 `lastDividendTime` 之后的新收益
- **防止重复提取**: 相同时间段内不会重复计算收益
- **时间戳持久化**: 每次提取后正确更新，为下次增量计算提供基准

### 3. 零收益处理
- 无收益记录时返回 0（不抛出错误）
- 重复提取时返回 0（已提取过，无新收益）
- 时间戳仍正确更新（即使收益为0）
- 交易成功完成（不会因为0值而失败）

### 4. 多场景增量提取
- **单次→单次**: 已提取单笔收益后，新增单笔收益的增量计算
- **单次→多次**: 已提取单笔收益后，新增多笔收益的累计计算
- **多次→单次**: 已累计提取后，新增单笔收益的增量计算
- **多次→多次**: 已累计提取后，新增多笔收益的累计计算

### 5. 多份额处理
- 遍历所有 HolderInfo 计算
- 提取后合并为单一记录
- 时间加权计算正确

### 6. 边界条件
- 售罄时间检查
- 零收益/零清算返回 0
- 时间截断不影响计算
- 参数验证（地址、时间戳）
